ART JOB CITY — 미술 직업 체험 웹앱

실행
  Python 3가 있는 환경에서:
    cd /workspace/artjob
    python3 -m http.server 8000 --bind 127.0.0.1
  브라우저에서 로컬 서버의 index.html을 엽니다.
  ES 모듈을 사용하므로 HTML 파일을 더블 클릭하는 file:// 실행 대신 HTTP 서버를 사용합니다.
  빌드·API 키·데이터베이스·npm 의존성 설치는 필요하지 않습니다.
  WebGL을 지원하는 최신 Chrome, Edge, Safari와 하드웨어 가속이 필요합니다.

GitHub Pages
  저장소 Settings > Pages에서 사용할 브랜치의 /(root)를 배포 원본으로 선택합니다.
  앱은 상대 경로만 사용하므로 /artjob/ 프로젝트 하위 경로에서도 작동합니다.
  Three.js 0.160.1과 라이선스는 vendor/에 포함되어 있으며 외부 CDN과 웹폰트를 요청하지 않습니다.
  코드 수정만으로 GitHub 배포가 수행되지는 않습니다. 배포는 저장소에 반영한 뒤 별도로 진행합니다.

체험
  1층 가구 디자이너: 실시간 3D 의자. 등받이 6종, 좌판 4종, 다리 5종,
    소재 8종, 기능 5종, 콘셉트 3종, 영감 4종과 자유 색상.
    소재별 컬러·범프 맵, 거칠기, 금속성, 투과와 조명 반사를 표현합니다.
    드래그로 수평·수직 회전, 휠 또는 +/- 버튼으로 확대·축소합니다.
  2층 게임 캐릭터 디자이너: 실루엣, 배지, 액세서리, 비례·색을 조합하는 2D 디자인.
  3층 공간 디자이너: 휴게실 구성, 바닥, 창·벽 장식, 비례·색을 조합하는 2D 공간 설계.
  4층 전시 기획자: 작품 배열, 추상 작품 유형, 전시실 조명을 조합하는 2D 전시 기획.
  5층 패션 디자이너: 의상 실루엣, 패턴, 액세서리, 비례·색을 조합하는 2D 패션 디자인.
  2~5층은 원화·도판·평면도 기반의 2D 제작 활동입니다. 요소 배치와 자유 드로잉을 지원하며 3D 시뮬레이션은 없습니다.

저장
  작품 이름과 기획 의도를 적고 '작품 초안 · 갤러리 저장'을 누릅니다.
  작품 이미지·디자인 설정이 현재 브라우저에 저장됩니다. 프로젝트 데스크에서 기록과 조건을 검토하고 제출하면 직업 배지가 저장됩니다.
  갤러리에서 PNG 다운로드, 디자인 이어하기, 작품 삭제가 가능합니다.
  브라우저 저장소 삭제, 시크릿 모드 종료, 기기 변경 시 작품이 유지되지 않을 수 있습니다.
  브라우저 용량이 한정되어 있으므로 중요한 작품은 PNG로도 내려받으세요.
  저장 용량이 부족하거나 저장이 차단되면 오류 안내가 표시됩니다.
  계정·교사 대시보드·클라우드 동기화는 포함되지 않습니다.

브라우저 자동 검증
  tests/smoke.cjs: 의자 편집, 새로고침 복원, PNG 다운로드, 다섯 체험실 저장,
    갤러리, 배지, PC·태블릿·모바일 너비와 브라우저 오류를 검사합니다.
  Playwright와 Chromium이 설치된 환경에서 서버를 시작한 뒤 실행합니다.
    node tests/smoke.cjs
  Playwright가 기본 모듈 경로에 없으면 ARTJOB_PLAYWRIGHT_PATH에 설치 디렉터리를 지정합니다.
  Chromium 경로는 ARTJOB_CHROMIUM, 서버 주소는 ARTJOB_BASE_URL로 지정할 수 있습니다.
  결과 이미지는 /tmp/artjob-browser-checks에 생성됩니다(ARTJOB_TEST_OUTPUT으로 변경 가능).

현재 클라우드 환경의 검증 예시
  ARTJOB_PLAYWRIGHT_PATH=/opt/codex/cua_node/lib/node_modules/playwright node tests/smoke.cjs

의뢰인과 전문가를 만나는 프로젝트 흐름
  체험실 첫 입장 시 '의뢰인에게서 메일이 왔어요' 알림과 날아오는 봉투가 표시됩니다.
  메일을 열면 직업별 전문가와 사무실 일러스트, 전달되는 의뢰서가 나타납니다.
  의뢰인·프로젝트 상황·디자인 조건 3개·제출할 작품을 읽고 디자인을 시작합니다.
  상단의 '의뢰서 다시 보기'로 언제든 다시 읽을 수 있습니다.
  작업 화면의 조건 체크는 학생의 자기 점검이며 자동 채점이 아닙니다.
  의뢰서 확인 상태와 체크 상태는 현재 브라우저에 저장됩니다.
  저장 작품에는 의뢰 정보도 포함되며 갤러리에 의뢰 제목이 표시됩니다.
  다섯 회사·전문가·의뢰인은 체험을 위한 가상 설정이며 실제 이메일 서비스는 사용하지 않습니다.
  assets/brief-*.webp는 이 프로젝트를 위해 생성한 전문가·사무실 일러스트입니다.
  tests/brief.cjs로 메일·서류·작업 진입·재열기·저장·반응형 흐름을 검증할 수 있습니다.

나의 디자이너 캐릭터
  로비의 '내 캐릭터 꾸미기'에서 여학생 또는 남학생을 선택합니다.
  각 캐릭터는 헤어스타일 3종과 후디·캠퍼스 재킷·카디건 3종을 조합합니다.
  머리·상의·하의·피부 색상과 안경·헤드폰, 이름을 바꿀 수 있습니다.
  assets/avatar-female.webp와 assets/avatar-male.webp의 일러스트를 조합해 렌더링합니다.
  선택한 모습은 artjob_profile_v1에 저장되며 새로고침 후에도 복원됩니다.
  저장하지 않고 닫으면 기존 모습이 유지됩니다.
  메일을 열면 내 캐릭터가 해당 직업 전문가와 인사하는 장면으로 이어집니다.
  '의뢰서 받아 보기'를 누르면 기존 프로젝트 의뢰서와 디자인 작업으로 이동합니다.
  작업실의 '전문가와 다시 만나기'로 만남 장면을 다시 볼 수 있습니다.
  저장 작품에는 당시 캐릭터 설정과 제작자 이름이 함께 기록됩니다.
  tests/avatar.cjs에서 그래픽 조합·색상·저장·만남·작품 연결·반응형을 검증합니다.

프로젝트형 직업 체험 업데이트
  각 작업실 상단 '프로젝트 데스크'에서 의뢰 분석 → 자료실 → 실험·비교 → 검토·제출을 진행합니다.
  각 직업에 맞는 사용자 상황, 설계 조건, 세부 읽기 자료 3개, 비교표와 참고 도판이 있습니다.
  참고 도판과 작업 베이스는 이 프로젝트를 위해 생성한 학습용 원화입니다.
  - 가구: 좌판 높이·폭·깊이, 등받이 각도와 수업용 제작 포인트를 실험합니다.
  - 게임 캐릭터: 세밀한 캐릭터 베이스 3종에 색·역할 표식·장비·드로잉을 적용합니다.
  - 공간: 6m×4m 축척 도면에 소파·테이블·의자·책장·식물을 이동·회전·확대 배치합니다.
  - 전시: 학습용 추상 도판 6종을 직접 걸고 크기·순서·간격을 구성합니다.
  - 패션: 의상 원화 3종에 색·직물 문양·포켓·패치·스티치를 적용합니다.
  요소는 마우스·터치로 이동하거나 선택 후 방향키(Shift로 미세 조절)로 이동할 수 있습니다.
  펜·지우개·되돌리기와 요소 삭제를 지원합니다.

  시안 A·B는 각각 실제 디자인 설정과 이미지로 기록하고 복원할 수 있습니다.
  사용자·문제·디자인 가설·개선 이유·최종 제안, 서로 다른 시안 2개와 화면의 의뢰 조건을 검토해야 제출됩니다.
  초안 저장은 완료 배지를 부여하지 않습니다. 프로젝트 제출 시 작품과 배지가 기록됩니다.
  기존에 획득한 배지는 유지됩니다. 자동 검토는 형식·치수·단순 배치 조건이며 미술적 가치를 자동 채점하지 않습니다.
  제작 포인트는 교실용 비교 모델로 실제 견적이 아닙니다. 공간 배치 검사도 실제 안전·피난 검토를 대신하지 않습니다.
  제안서 다운로드는 작품·시안·설명·검토·자기 평가를 포함한 독립 HTML 파일입니다.
  내려받은 파일을 브라우저에서 열어 인쇄하거나 PDF로 저장할 수 있습니다.

  액세서리는 원화 18개 조합의 눈·귀·정수리 좌표에 고정하여 피부색에 따라 위치가 흔들리지 않습니다.
  메일 알림과 의뢰서 화면은 각각 한 화면에 표시됩니다.
  PC·태블릿·세로 휴대폰(최소 검증 390×667)을 검증했습니다. 자료실·프로젝트 데스크는 상세 내용을 위해 내부 스크롤을 사용합니다.

  새 검증: ARTJOB_PLAYWRIGHT_PATH=/opt/codex/cua_node/lib/node_modules/playwright node tests/revision.cjs
  프로젝트 제출만 검사: ARTJOB_PROJECT_ONLY=1을 추가합니다.
